## About

While singly linked lists allow navigation in one direction, doubly linked lists empower bidirectional movement. This opens up a world of possibilities. Doubly linked lists are the underlying data structure that we use in our simple everyday tasks like move back and forth between tabs in a web browser. They are also the underlying data structure in complex technologies like blockchain. In this module, let us understand what a doubly linked list is and how we can implement one in Java.
